# Weather App

An interactive map that shows real-time weather conditions for a set of pinned locations. Built with React and the Google Maps API, it plots markers on a map and, for each one, pulls current conditions — temperature, humidity, wind speed and direction, precipitation chance, and a short forecast description — from the National Weather Service API.

The project was bootstrapped with Create React App and uses a simple component structure (map display, markers, and supporting UI elements like a modal and loading spinner) to keep the weather-lookup logic separate from the map rendering.
